模数转换器测试规范

概述
本测试为模数转换器通用验证和测试规范，范围为通用功能规范。
模数转换器（Analog-to-Digital Converter, ADC）是一种输入为模拟信号，输出为数字信号的混合信号集成电路（Mixed-Signal Device）。

DOUT=2n× G × AIN / VREF
n=输出比特数，即分辨率
G=增益，通常为1
AIN=输入模拟电压信号或电流信号
VREF(IREF)=参考电压或电流信号
参数简介
分辨率
分辨率n是用于表示模拟信号的位数；对于3-bit ADC，共有8种输出码；例如，参考电压VREF=8V，输入电压VIN=5.5V，则输出编码为101；分辨率越高，ADC可识别更小的输入电压变化；采用更低的参考电压也可以提高转换精度，但这是以牺牲噪声特性为代价的。

失调误差
失调误差（ Offset error）定义为输入信号为零时输出信号不为零的值，ADC输入输出曲线中第一个转换点与理想值间的偏差，可以用满摆幅信号百分比、电压或LSB形式表示。偏移误差会使实际的传递函数与理想传递函数间存在一个固定的偏移。其通常是实际与理想模数转换器中分别对应的最低判决电平之间的差值。计算方法：输出第一个代码时ADC的实际输入模拟值减去1/2LSB值再减去理想的0代码输入模拟值

图 STYLEREF 1 \s 1SEQ 图 \* ARABIC \s 113 ADC失调误差
可以使用两点法进行偏移误差和增益误差的计算。

增益误差
增益误差（Gain error）反映了实际与理想转换函数斜率一致性的指标，是指去掉失调误差，即将实际与理想数模转换器转移曲线中的最低判决电平对齐后,两者最高判决电平之间的差值。通常在模数转换器的最末或最后一个传输代码转换点计算。计算方法：实际的满幅输出代码值加上1/2LSB值，再加上失调误差。

测试阶段
模数转换器模块软件验证生命周期阶段分为三个阶段：芯片功能验证、芯片性能评测和芯片生产测试阶段。
芯片验证
复位值测试
测试ADC的所有寄存器复位值是否与手册一致。测试方式主要为在芯片刚上电复位后读取ADC所有寄存器的值，对比是否与手册说明复位值一致。
寄存器扫描
依次对ADC寄存器能够写入的位进行写“1”与写“0”操作，在每次操作后判断是否成功写入。

连续转换
测试一：设置连续转换模式，只开启一次软件转换。首先给输入管脚施加电压1/4Vref，读取ADC的转换结果寄存器并存储为D1，给输入管脚加电压1/2Vref，读取ADC的转换结果寄存器并存储为D2，给输入管脚加电压Vref，读取ADC的转换结果寄存器并存储为D3，通过软件程序比对D1、D2、D3的数字量与标准量之间的差值，如果差值小于10mV则代表连续转换模式正确。
测试二：配置ADC模块中断模式，在中断中对GPIO口进行翻转，软件配置为最小采样时间和最小的转换时间，在最大采样率下进行功能验证，通过EOC中断输出管脚电平翻转频率Freq，与芯片设计的最大采样速率Fmax进行对比，如果Freq=Fmax则代表功能正确。
注：如果芯片没有明确的连续转换模式，可以采用组转换模式单通道进行功能替换验证。
触发事件
测试一：配置ADC模块为软件手动开启触发，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表软件触发正确；
测试二：配置ADC模块为内部定时事件触发，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表内部定时器触发正确；
测试三：配置ADC模块为外部管脚触发，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表外部触发正确。
模块时钟范围
测试一：配置ADC的时钟为规范中的最大值，模块配置为最小采样时间和最小的转换时间，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
测试二：配置ADC的时钟为规范中的最小值，模块配置为最小采样时间和最小的转换时间，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
模块时钟分频系数
测试一：配置ADC的时钟分频系数为最小值，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
测试二：配置ADC的时钟分频系数为最大值，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
测试三：配置ADC的时钟分频系数为手册寄存器的中间值，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
采样和转换时间测试
根据手册寄存器中的采样时间设置寄存器进行所有可以配置的采样时间Ts的测试，并通过连续转换模式和中断功能来验证采样时间是否设置正确。
判断标准为中断中IO翻转的频率Freq等于1/(Ts+Tv)*2。
最高转换速率
测试ADC实际工作时的最高采样速率。
测试按下列程序进行：
在规定的环境温度下，将被测ADC接入测试系统中；
施加规定的电源电压和参考电压；
按要求使ADC时钟输入工作于最高转换率条件下；
测试该条件下待测试器件工作是否达到设计要求；
注意：一般使用动态误差指标（如SNR等）来判断器件工作是否达到器件工作是否达到设计要求。

DMA功能测试
测试一：配置最高采样速率，配置DMA触发方式，配置每次触发转换的序列个数并对应不同通道号，源地址设置为ADC的数据寄存器，目的地址设置为内存地址，使能模块和使能DMA，判断寄存器中的值转换成电压后是否与通道给定的电压值一致，如果一致则测试通过。
中断
ADC模块一般会有EOC结束转换中断。
测试一：将ADC配置成连续转换模式，使能ADC模块中断，通过中断中将转换结果存储到内存中来观察ADC是否进入中断。

通道电压对比
通道电压对比是为了测试通道之间测试结果之间的差异来判断通道一致性。
测试一：所有外部管脚输入一致的1/2*Vref电压值进行ADC采样，每个通道都采样16次做平均值作为采样结果，计算16个通道的平均值，如果采样结果都在[Vmean-5LSB,Vmean+5LSB] 电压值则测试通过。
测试二：所有外部管脚输入一致的0V电压值进行ADC采样，每个通道都采样16次做平均值作为采样结果，计算16个通道的平均值，如果采样结果都在[Vmean-5LSB,Vmean+5LSB] 电压值则测试通过。
测试三：所有外部管脚输入一致的Vref电压值进行ADC采样，每个通道都采样16次做平均值作为采样结果，计算16个通道的平均值，如果采样结果都在[Vmean-5LSB,Vmean+5LSB] 电压值则测试通过。

W[k] = T[k+1] − T[k]
d) 按照步骤c)分别测试所有码（或根据转换器结构通过测量特定的码值子集计算出所有码）的码宽电压。
e) 记步骤d)计算出的ADC所有码宽电压的绝对值最大值W[k]max。
f) 由公式计算求出 DNL：
DNL=[(W[k]max−VLSB)/VFSR]×100
式中：
DNL —— 微分非线性误差，%FSR；
VLSB——1个LSB电压，V；
W[k] max——ADC绝对值最大码宽电压，V；
VFSR ——满幅度电压范围，V。
或
DNL=(W[k] max−VLSB)/VLSB
式中：
DNL——微分非线性误差，LSB；
VLSB——1个LSB电压，V；
W[k] max—— ADC绝对值最大码宽电压，V。

标准积分非线性INL
测试实际转换特性曲线与最佳拟合直线间的最大偏差。
测试按下列程序进行:
a)在规定的环境温度下,将被测ADC接入测试系统中。
b)施加规定的电源电压和参考电压。
c)按照定义测试所有码值(或根据转换器结构通过测量特定的码值子集计算出所有码值)的码值转换电平𝑇[𝑘]。
d)按规定的数学方法确定码值转换电平最佳拟合直线(如最小二乘法、端点直线法等),得到测量转换电平在拟合直线上所对应的点𝑇′[𝑘]。
e) 将c)的数据与d)的数据相比较,得到𝑇[𝑘]减去𝑇′[𝑘]的结果中绝对值最大值Δ𝑉max。
f)由公式计算出𝐼𝑁𝐿:
𝐼𝑁𝐿=Δ𝑉max/𝑉FSR×100
式中:
𝐼𝑁𝐿——积分非线性;
𝑉LSB——1个LSB电压,V;
Δ𝑉max——ADC 实际码值转换电平和拟合直线上该点所对应值之差,V;
𝑉FSR——满幅度电压范围,V。
或
𝐼𝑁𝐿=Δ𝑉max/𝑉LSB
式中:
𝐼𝑁𝐿——积分非线性,LSB;
𝑉LSB——1个LSB 电压,V;
Δ𝑉max——ADC实际码值转换电平和拟合直线上该点所对应值之差,V。

有两种方法，分别是单极性起始点计算法和双极性中间点计算法。

双极性中间点计算法测试按照下列程序进行：

标准增益误差GAIN
测试转换器实际满量程输入范围和理想满量程输入范围的偏差。
单极性起始点计算法测试按照下列程序进行：
在规定的环境温度下，将被测ADC接入测试系统中。
施加规定的电源电压和参考电压。
按照定义测试码值1的码值转换电平T[1]。
按照定义测试码值2N-1的码值转换电平T[2N-1]

EG= {[(T[2N-1] - T[1])/(VFSR-2×VLSB)]-1}×100

void AnalyseData(void)
{
    long i, H, L, len;
    float ft, hit0;

    /* 1. 从尾部向前找第一个满足 data[i] >= HIHPOINTER 的位置 H */
    for (i = CAPTURELEN - 1; i > 0; i--)
    {
        if (data[i] >= HIHPOINTER) break;
    }
    H = i;

    /* 2. 从头部向后找第一个满足 data[i] <  LOWPOINTER 的位置 L */
    for (i = 0; i < CAPTURELEN; i++)
    {
        if (data[i] < LOWPOINTER) break;
    }
    L = i;

    len = data[H] - data[L];

    /* 3. 统计 [L, H] 区间内各码值出现的次数 */
    for (i = 0; i < CODENUM; i++) hit[i] = 0;
    for (i = L; i <= H; i++)      hit[data[i]]++;

    /* 4. 累加 [LOWPOINTER, HIHPOINTER] 的直方图，求占比 hit0 */
    for (ft = 0, i = LOWPOINTER; i <= HIHPOINTER; i++)
        ft += hit[i];
    hit0 = ft / len;

    /* 5. 在 dnl[] 中找绝对值最大的一项 → DNL */
    for (ft = 0, i = LOWPOINTER; i <= HIHPOINTER; i++)
        if (fabs(dnl[i]) > fabs(ft)) ft = dnl[i];
    DNL = ft;

    /* 6. 在 inl[] 中找绝对值最大的一项 → INL */
    for (ft = 0, i = LOWPOINTER; i <= HIHPOINTER; i++)
        if (fabs(inl[i]) > fabs(ft)) ft = inl[i];
    INL = ft;
}

动态性能测试
动态性能参数测试主要测试参数包括：
1、信噪比失真（SINAD）
2、信噪比（SNR）
3、无杂散动态范围（SFDR）
4、有效位数（ENOB）
5、总谐波失真（THD）
动态性能测试一般将ADC触发方式配置成使用外部管脚触发，在EOC转换结束中断程序中将转换结果输出至GPIO的连续并行口，以供主控制端进行采样。需要测试的参数包含ENOB、SNR、SINAD、SFDR、THD等。如果Datasheet中要求的采样速率大于1Msps，则可以用DMA传输方式进行采样。
动态测试需要注意的是如果测试结果与预期差距较大，需要排除GPIO翻转带来的影响。由于动态测试转换数据所需要的存储空间有限，可以将所有的数据保存到片上存储空间，等待所有数据都转换结束后，再将存储空间中的数据与测试机进行交互传输。

同步模式
验证多ADC模拟核在同步采样条件下，各模拟的ENOB是否达到设计要求。
测试按下列程序进行：
a) 环境配置
在规定的环境温度下，将各ADC接入测试系统；
施加规定的电源电压和参考电压；
将所有ADC的时钟配置为同一ADCCLK（如共用同一个PLL输出的ADCCLK）；
将所有ADC的采样时间 Ts、转换时间 Tconv 配置为同一数值；
将所有ADC的触发方式配置为同一个外部触发信号（外部管脚触发，触发源来自同一触发）；
将各ADC精度配置为目标测试的精度档位。
b) 信号输入
使用同一信号源同时向所有待测ADC的模拟输入端注入满量程正弦信号 V_IN，频率 F_signal 满足相干采样要求（M与N_sample互质）；各ADC输入端信号幅度、相位、频率一致。
c) 数据采集，ENOB计算
判定标准
每个ADC的ENOB≥Datasheet规定的同步模式指标值；
各ADC之间的ENOB差值 ΔENOB≤0.5 bit（或Datasheet规定的同步一致性指标）。
异步模式
测试异步模式下的ENOB，异步模式在不同封装可能会有影响。
验证在多个 ADC 模拟核工作条件互相独立（时钟、采样保持时间、触发、精度均不同）的"异步"混合运行场景下，被测 ADC 的性能是否仍能保持指标要求，评估异步工作条件下其他 ADC 对被测 ADC 的干扰。
测试按下列程序进行：
被测 ADC 模拟核运行在与其他 ADC 混杂的 ADCCLK、S+H 持续时间、触发以及精度条件下。
a) 环境配置
在规定的环境温度下，将各ADC接入测试系统；
施加规定的电源电压和参考电压；
将被测 ADC 配置为目标测试的精度档位；
将其他 ADC 分别配置为不同的运行条件：
不同的 ADCCLK 分频系数（如 ADC1 用 1:1、ADC2 用 1:2、ADC3 用 1:4）；
不同的采样时间 Ts 和转换时间 Tconv；
不同的触发方式（软件触发/内部定时/外部触发）；
不同的精度档位（如ADCA最高档、ADCB中档、ADCC最低档）；
若 ADC 模块只有单一精度档位，则通过配置不同的 ADCCLK、S+H 持续时间或触发信号实现"异步"；
各 ADC 使用不同的信号源或不同频率/相位的信号注入，确保信号之间无相干性。
b) 信号输入
向被测 ADC 输入满量程正弦信号（频率 F_signal 满足相干采样要求）；
向其他 ADC 输入不同频率的正弦信号或直流偏置，避免与被测 ADC 信号产生相干干扰；
各ADC信号幅度、相位独立。
c) 数据采集、ENOB计算
判定标准
被测ADC的ENOB≥Datasheet规定的异步模式指标值；
异步模式下ENOB相对同步参考值的劣化ΔENOB_异步≤ 1bit（或 Datasheet 规定值）。

异常处理测试
1.过压保护测试
验证当输入电压超过ADC的最大额定值时，ADC是否正确进入保护状态而不被损坏，并产生相应的错误标志或者中断。
2.电源电压稳定性测试
测试ADC在电源电压波动时的响应，确保在指定的工作电压范围内都能稳定工作。
机测
模数转换器的机测测试板如果不做特殊处理干扰较大，测试转换精度波动较大。所以在条件允许的情况下，可以针对测试板的模拟参考电源做特殊处理，较为简单精准的方式是使用REF参考芯片，优点是电压稳定性好干扰较小，缺点是一般芯片电压不可控导致参考电压范围测试较为困难；较为复杂和精度一般的方式是使用比如DAC8552类芯片或者测试机本身的电压参考输入。
对于高精度要求的芯片生产测试需要使用带模拟测试模块的专业ATE测试机进行测试。
复位值测试
测试ADC的所有寄存器复位值是否与手册一致。测试方式主要为在芯片刚上电复位后读取ADC所有寄存器的值，对比是否与手册说明复位值一致。
寄存器扫描

中断
ADC模块一般会有EOC结束转换中断。
测试一：将ADC配置成连续转换模式，使能ADC模块中断，通过中断中将转换结果存储到内存中来观察ADC是否进入中断。
触发事件
测试一：配置ADC模块为软件手动开启触发，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表软件触发正确；
测试二：配置ADC模块为内部定时事件触发，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表内部定时器触发正确；
测试三：配置ADC模块为外部管脚触发，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表外部管脚触发正确。
模块时钟范围
测试一：配置ADC的时钟为规范中的最大值，模块配置为最小采样时间和最小的转换时间，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
测试二：配置ADC的时钟为规范中的最小值，模块配置为最小采样时间和最小的转换时间，外部管脚输入指定1/2Vref电压值进行ADC采样，如果采样结果等于1/2Vref电压值则代表当前时钟可以正常工作。
采样和转换时间测试
根据手册寄存器中的采样时间设置寄存器进行所有可以配置的采样时间Ts的测试，并通过连续转换模式和中断功能来验证采样时间是否设置正确。判断标准为中断IO翻转的频率Freq等于1/(Ts+Tv)*2。
如果转换速率大于1MSps，通过DMA方式传输，GPIO口输出进行判断。机测码将DMA传输数据量设置为32768，GPIOx口初始化配置成输出低，ATE更改机测码前通过文件中GPIOx的输出状态为高后给定触发信号，记录触发信号的时间点t1，DMA传输完成后机测码将GPIO口拉低，记录DMA传输完成的时间点为t2。采样转换时间 tconv = (t2 - t1)/32768，采样速率fs = 1/tconv。
DMA功能测试
测试一：配置最高采样速率，配置DMA触发方式，配置每次触发转换的序列个数并对应不同通道号，源地址设置为ADC的数据寄存器，目的地址设置为内存地址，使能模块和使能DMA，判断寄存器中的值转换成电压后是否与通道给定的电压值一致，如果一致则测试通过。

静态性能测试一般将ADC触发方式配置成使用外部管脚触发，在EOC中断程序中将转换结果输出至GPIO的连续并行口，以供测试机进行采样。需要测试的参数包含INL、DNL、OFFSET、GAIN等。

同步模式
测试同步模式下的ENOB。满足以下所有条件：
条件1：
所有ADC模拟核用同一个ADCCLK
条件2：
S+H采样保持持续时间一致
条件3：
所有ADC的触发信号保持一致
条件4：
所有ADC的精度保持一致
异步模式
测试异步模式下的ENOB，异步模式在不同封装可能会有影响。
条件：所有的ADC模拟核运行在混杂的ADCCLK、S+H持续时间、触发以及精度。测试配置当前ADC模拟核为目标测试的精度，其它模拟核配置为不同的精度。如果ADC模块只有单一的精度，则不同ADC需要配置不同的ADCCLK、S+H持续时间或者触发信号。
校准
ADC的校准主要分为OFFSET TRIM和INLTRIM的校准，校准值一般写入片上OTP固定区域。12位ADC一般情况下只校准OFFSET TRIM，16位ADC一般情况下需要校准OFFSET TRIM和INL TRIM。通过后门进行ADC的OFFSET校准，通过中间点进行校准，将校准值通过后门写入OTP固定区域。INL TRIM根据具体芯片的校准方法进行校准。
注意：ADC进行校准时如果用到外部基准电压需要首先校准基准电压芯片，确保基准电压误差范围在0.001V以内。
机测ATE模拟专用板绘制注意点
ATE模拟专用板只有在需要进行高精度测试的情况下需要绘制。
16位差分ADC
以下要求需要在ATE模拟板绘制前送交检测中心PCB绘制人员：
1、满足ADC每个模拟核至少一对差分通道测试。
2、满足DAC的通道（优先布局ADC的各个芯片和走线）。
3、ADC参考源采用ADR421（优先考虑）/REF5025或者更高性能芯片
4、模拟电源采用ADP7104ARDZ-R7/ADP7185或者更高性能低噪声LDO芯片，避免使用开关电源，LDO输入端加π型滤波（用其它滤波电路也可以），去耦电容紧贴ADC电源引脚（距离<5mm）（典型组合10uF钽电容（<3cm）+0.1uF陶瓷0603+1nF高频陶瓷0402）。
5、REF参考源芯片离芯片尽量近，走线长度<10mm，走线宽度（建议20mil以上粗线，两侧用地线包裹），禁止与其他信号平行走线。
6、ADC的前端输入要有滤波电路，可以暂不焊接。
7、模拟地与数字地在芯片正下方通过0Ω电阻或高频磁珠单点连接，禁止大面积分割地平面。
8、模拟输入的管脚PCB走线要跟数字管脚分向放置，禁止走线跨越，模拟走线与时钟线、数字总线间距≥3倍线宽。
9、时钟触发GPIO口使用50Ω阻抗控制，禁止跨越模拟区。
10、PCB设计要考虑差分走线（等长、对称、平行）、数模干扰等。
11、完整地平面优先：模拟区域下方的地平面必须保持完整，不得有信号线穿入。
12、芯片背面如果要走线或布线需要考虑耦合因素，要注意这方面的考虑。

机测阶段进行ADC性能测试的注意点
机测阶段尽量使用芯片的测试模式（也称作后门模式）进行芯片的性能参数测试，可以将SOC其它模块和管脚的影响降至最低，提高测试结果的精度；同时也能满足以最大速率进行采样并且结果输出。
机测阶段若没有后门模式，可以通过前门进行测试，要将其它不相关模块进行关闭，临近ADC测试管脚的其余管脚需要固定电平，尽量不进行翻转。
通过前门测试，软件测试人员需要将ADC触发配置成外部管脚触发模式，通过中断或者DMA将转换结果输出到功能管脚上，供测试机进行并行读取。（某些ADC的转换时间很短，可以达到很高的转换速率，中断方式一般支持1Msps以下的采样率，1Msps以上的采样率可以通过DMA方式进行传输）。前门测试有局限性，采样速率可能会有限制达不到最大速率，测试人员可以使用DMA方式进行速率测试判断。
根据项目要求可以将校准参数写入OTP空间或寄存器映射空间，通过调用接口函数读相应参数来进行参数校准。

硬件设计要求
核心控制组件：
微控制器：一般推荐使用STM32F417系列作为主控芯片
互连器件：一般推荐使用FPGA器件实现控制信号和数据信号的互连
待测器件：考虑信号质量一般推荐直接板上直焊，如果需要做通用板可以考虑使用核心板插座方式来实现；
信号转换器件：差分放大器来实现从单端信号到差分信号的转换；
模拟开关：考虑单端条件下的模拟开关，单端信号可以使用8通道的模拟开关实现单端信号的接入，差分信号慎用。
信号源：这里使用SMA接口外接输入信号，一般信号源为单端信号输入；
参考电压基准芯片：考虑到测试精度一般使用专用电压基准芯片如REF5025AIDR等芯片；如果更多的是考虑可以测试多电压基准也可以使用如DAC8552芯片进行电压基准的调节，精度比电压基准芯片差；
电源管理：提供稳定的电源给ADC和控制器，考虑到测试精度一般使用LDO或者专用线性电源芯片来进行供电；如果更多的是考虑可以测试多电压基准也可以使用如DAC8552芯片或者外接电压源来进行电压基准的调节。
数据存储芯片：一般推荐使用FSMC或者EMIF接口来外接SDRAM外部存储芯片来实现内存扩展，大小一般推荐1MB~16MB的存储芯片，具体大小可以根据公式计算；
晶振：提供片上高精度时钟用，精度越高越好，如0.1%的无源晶振。
主要接口：
JTAG口：微控制器、FPGA以及待测DUT三个调试口都需要引出来；
外部数据通信口：微控制器串口、待测DUT的串口都要引出来；预留USB通信接口以便后续开发；
内部通信口：微控制器跟DUT间的数据通信接口可以使用SPI或者UART接口；
内部数据通信口：ADC结果输出可以通过并口传输，比如待测DUT芯片的GPIO0-15作为输出，微控制器的GPIOPA0-PA15作为输入，互连进行数据传输。
